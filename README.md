## Что здесь

В проекте анализируются транзации по подписке за 3 месяца (с 01.04.2025 по 30.06.2025) со способом оплаты: wallet
В данных хранится информации по успешным и отмененным операциям за период, а также сумма списаний
В Дз1 был проведен EDA и первично проанализирован анализируемый участок: были исследованы доли успешных и неуспешных операций по подпискам, выручка, полученная от успешных платежей, в различных временных разрезов, распределение суммы списаний относительно периода

## Как запустить

Нужны [Git](https://git-scm.com/) и [uv](https://docs.astral.sh/uv/).
Python отдельно ставить не нужно — его поставит uv.

```bash
git clone git@github.com:ВАШ_ЛОГИН/prime-monitor.git
cd prime-monitor
uv sync
```

Доступ к учебной базе выдаёт бот курса по команде `/db`. Полученную строку
подключения кладём в `.env`:

```bash
cp .env.example .env
# и вписать в .env строку из бота
```

Проверка, что всё встало:

```bash
uv run python -c "from prime.config import get_engine; print(get_engine().connect().execute(__import__('sqlalchemy').text('select current_user')).scalar())"
```

Запуск JupyterLab:

```bash
uv run jupyter lab
```
